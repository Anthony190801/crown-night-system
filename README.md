# Crown Night System

Sistema desarrollado por el Área TI de SEDIPRO UNT para automatizar el proceso de registro, validación y gestión de participantes del proyecto **Crown Night 2026**.

## Funcionalidades

- Registro automático desde Google Forms.
- Generación de códigos alfanuméricos únicos.
- Generación automática de códigos QR.
- Validación de pagos.
- Envío masivo de tickets por correo.
- Dashboard de resultados.
- Conteo de votos.
- Reportes automáticos.

## Tecnologías

- Google Forms
- Google Sheets
- Google Apps Script
- Gmail Service
